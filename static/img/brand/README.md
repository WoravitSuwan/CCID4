# CCID4 logo

ตราที่หน่วยส่งมา (ภาพพื้นขาว ชัดที่สุดในบรรดาภาพที่ได้มา) ตัดเฉพาะโล่ พื้นหลังโปร่งใส ไม่ได้วาดหรือแก้ลายตรา ใช้เป็นโลโก้ค่าเริ่มต้นของระบบ
(แถบเมนู หน้าเข้าสู่ระบบ ไอคอนแท็บ ไอคอนหน้าจอโทรศัพท์) ถ้าผู้ดูแลอัปโหลดโลโก้ที่ ตั้งค่า → ระบบ จะใช้รูปนั้นแทน

- `ccid4-logo-256.png` หน้าเข้าสู่ระบบ · `ccid4-logo-128.png` แถบเมนู · `ccid4-logo-64.png` แถบมือถือ
- `favicon.ico`, `favicon-32.png` ไอคอนแท็บ · `apple-touch-icon.png` ไอคอนหน้าจอโทรศัพท์

ได้ไฟล์ต้นฉบับความละเอียดสูงแล้ว ให้แทนไฟล์เหล่านี้ด้วยขนาดเดิม (ภาพสี่เหลี่ยมจัตุรัส พื้นใส)
