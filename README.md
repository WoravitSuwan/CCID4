# ระบบออกหมายเรียกผู้กล่าวหา (บก.สอท.4)

เว็บแอปภายในหน่วยงาน ทำหน้าที่ดังนี้
- นำเข้าข้อมูลผู้แจ้งและทะเบียนคดีจาก Excel แล้วรวมกันด้วยเลขรับแจ้ง
- คัดคดีที่ยังไม่สิ้นสุด
- ออกหมายเรียกผู้กล่าวหาจากแบบฟอร์ม Word ของหน่วย ได้ทีละคนหรือหลายร้อยคนพร้อมกัน
- ส่งออกเป็น Word / PDF พร้อมใบจ่าหน้าซอง

ข้อมูลทั้งหมดเก็บบนเครื่องภายในหน่วยงาน ระบบไม่เรียก API ภายนอกใดๆ

| ส่วนประกอบ | เทคโนโลยี |
|---|---|
| เว็บ | Python 3.12, Django 5.2, HTMX, Tailwind CSS (คอมไพล์ไว้แล้ว ไม่ต้องใช้อินเทอร์เน็ต) |
| ฐานข้อมูล | PostgreSQL 16 |
| งานเบื้องหลัง | Celery + Redis |
| เอกสาร | python-docx, docxcompose, LibreOffice (แปลง PDF) |

### แบบที่ 1: Docker (ใช้งานจริง) — แนะนำ
ระบบใช้งานจริงรันด้วย Docker: PostgreSQL, Redis, งานเบื้องหลัง (Celery) และ LibreOffice (Writer สำหรับหมายเรียก/ซอง และ Calc สำหรับรายงานแก้สถานะ) อยู่ใน container ทั้งหมด

| เครื่อง | ทำอย่างไร |
|---|---|
| Windows | ติดตั้งและเปิด Docker Desktop แล้วดับเบิลคลิก **`start-docker.bat`** |
| Linux / macOS | ติดตั้ง Docker แล้วรัน `./start-docker.sh` |

- ครั้งแรกจะสร้าง `.env` พร้อมรหัสผ่านสุ่มให้เอง
- build image (ครั้งแรกหลายนาที) แล้วเปิดระบบที่ <http://localhost:8000>
- รหัสผ่าน `admin` แสดงบนหน้าจอและอยู่ใน `data/admin-password.txt`
- **เข้าระบบไม่ได้ / ลืมรหัสผ่าน admin:** เปิดระบบไว้ แล้วดับเบิลคลิก **`reset-admin-password.bat`** (Linux/macOS: `./reset-admin-password.sh`) ระบบตั้งรหัสผ่านใหม่และแสดงบนหน้าจอ
  - สาเหตุที่พบบ่อย: บัญชี `admin` ถูกสร้างครั้งเดียวตอนฐานข้อมูลยังว่าง ถ้าฐานข้อมูล (Docker volume) มีอยู่แล้วจากการติดตั้งครั้งก่อน แล้ว `.env` ถูกสร้างใหม่ รหัสใน `data/admin-password.txt` จะเป็นรหัสใหม่ที่ไม่ได้ใช้กับบัญชีเดิม
- ข้อมูลทั้งหมด (ฐานข้อมูล ไฟล์แนบการโทร) อยู่ใน Docker volume ไม่หายเมื่อปิดหรือรีสตาร์ตเครื่อง

รายละเอียดการติดตั้ง สำรองข้อมูล และอัปเดต อยู่ในข้อ 1 และข้อ 4

### แบบที่ 2: รันบนเครื่องนี้โดยไม่ใช้ Docker (ทดลอง / เครื่องเดียว)
ดับเบิลคลิก **`start-local.bat`** (macOS/Linux: `./start-local.sh`)

ครั้งแรกระบบจะ:
- หา Python 3.11 ขึ้นไป ถ้าไม่มีจะติดตั้ง Python 3.12 ให้ผ่าน winget (ติดตั้งเสร็จแล้วให้ดับเบิลคลิกอีกครั้ง)
- สร้าง `.venv` และติดตั้งแพ็กเกจ (ใช้เวลา 1–3 นาที ต้องต่ออินเทอร์เน็ตครั้งแรก)
- สร้างฐานข้อมูล SQLite ใน `data\` และบัญชีผู้ดูแลระบบ `admin` พร้อมรหัสผ่านสุ่ม
  - แสดงรหัสผ่านบนหน้าจอ และบันทึกไว้ใน `data\admin-password.txt`
- ถ้าไม่พบ LibreOffice จะถามว่าจะติดตั้งให้หรือไม่ (ไม่มี LibreOffice ก็ใช้งานได้และส่งออก Word ได้ แต่สร้าง PDF ไม่ได้)
- เปิดเบราว์เซอร์ที่ <http://localhost:8000>

ครั้งต่อไปดับเบิลคลิกไฟล์เดิม ระบบจะเปิดทันที ปิดระบบให้ปิดหน้าต่างสีดำ ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data\` และ `media\` (สำรองโดยคัดลอก 2 โฟลเดอร์นี้ขณะปิดระบบ)

| ต้องการ | ทำอย่างไร |
|---|---|
| ลองระบบด้วยข้อมูลสมมติ | เปิด Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วพิมพ์ `start-local.bat demo` (ใช้กับเครื่องทดลองเท่านั้น) |
| เปลี่ยนพอร์ต / ใช้ PostgreSQL แทน SQLite | สร้างไฟล์ `local.env` (บรรทัดละ `KEY=VALUE`) เช่น `PORT=8080` หรือ `POSTGRES_HOST=localhost` กับ `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` |
| ให้เครื่องอื่นในเครือข่ายเข้าใช้ | ใช้ที่อยู่ `http://<IP>:8000` ที่แสดงบนหน้าจอ และอนุญาต Python ใน Windows Firewall |

> **ฟอนต์:** ติดตั้ง TH SarabunIT๙ และ TH Sarabun New ใน Windows (คลิกขวาไฟล์ฟอนต์ → Install for all users) เพื่อให้ PDF ตรงกับแบบฟอร์ม

## 1. ติดตั้งด้วย Docker (Windows / Linux)

### 1.1 เตรียมเครื่อง (ครั้งเดียว)
1. ติดตั้ง **Docker Desktop for Windows** (เปิดใช้ WSL 2 ตามที่ตัวติดตั้งแนะนำ) แล้วรีสตาร์ตเครื่อง
   - เซิร์ฟเวอร์ Linux: ติดตั้ง Docker Engine และ compose plugin แล้ว `sudo systemctl enable --now docker`
2. เปิด Docker Desktop ให้ขึ้นสถานะ *Engine running*
3. ใน Docker Desktop ไปที่ Settings → General แล้วติ๊ก *Start Docker Desktop when you sign in* เพื่อให้ระบบเปิดเองหลังรีสตาร์ต

### 1.2 นำโค้ดมาไว้ในเครื่อง
ดาวน์โหลดโค้ด (ZIP หรือ `git clone`) ไว้ที่ เช่น `C:\ccid4` แล้วเปิด **PowerShell** ในโฟลเดอร์นั้น

```powershell
cd C:\ccid4
```

### 1.3 ใส่ฟอนต์
คัดลอกไฟล์ฟอนต์ **TH SarabunIT๙** และ **TH Sarabun New** (.ttf ทั้งตัวปกติ ตัวหนา ตัวเอียง) ไปไว้ในโฟลเดอร์ `fonts\` ดูรายละเอียดใน [fonts/README.md](fonts/README.md)
- หมายเรียกใช้ TH SarabunIT๙
- ใบจ่าหน้าซองใช้ TH Sarabun New เพราะซองจริงใช้ตัวเลขแบบอารบิก (370, 50180) ส่วน TH SarabunIT๙ แสดงตัวเลขเป็นรูปเลขไทย
- ใบจ่าหน้าซองเริ่มต้นเป็น A4 แนวตั้งแบบพับ 3 ทบ (หน้าซองอยู่ 1/3 บน เส้นประพับที่ 9.9 ซม. จากขอบบน) แนวเดียวกับหมายเรียก สั่งพิมพ์รวดเดียวได้ ถ้าต้องการแบบแนวนอน เลือกได้ที่ ตั้งค่า → แบบฟอร์ม

> ถ้าไม่ใส่ฟอนต์ Docker image จะใช้ฟอนต์สำรอง "Sarabun Compat" (สร้างจาก Laksaman แล้วย่อให้ขนาดเท่า TH SarabunIT๙) PDF จะได้เลย์เอาต์ใกล้เคียงแบบฟอร์ม แต่รูปตัวอักษรต่างเล็กน้อย
> PDF จะใกล้เคียงแต่ตัวเลขไทยไม่ใช่แบบ IT๙ หลังใส่ฟอนต์ต้อง build ใหม่ (ข้อ 1.5)

### 1.4 ตั้งค่า
`start-docker.bat` / `start-docker.sh` สร้าง `.env` พร้อมรหัสผ่านสุ่มให้เองตอนเปิดครั้งแรก ถ้าจะตั้งเองให้ทำก่อนเปิดระบบ:
```powershell
Copy-Item .env.example .env
notepad .env
```
แก้อย่างน้อย `DJANGO_SECRET_KEY`, `POSTGRES_PASSWORD`, `DJANGO_SUPERUSER_PASSWORD`
ถ้าจะเปิดจากเครื่องอื่นผ่าน IP ให้ใส่ `DJANGO_CSRF_TRUSTED_ORIGINS=http://<IP เครื่องนี้>:8000`

สร้าง SECRET_KEY แบบสุ่มได้ด้วยคำสั่ง
```powershell
-join ((48..57)+(65..90)+(97..122) | Get-Random -Count 60 | % {[char]$_})
```

### 1.5 เปิดระบบ
ดับเบิลคลิก `start-docker.bat` (Linux: `./start-docker.sh`) หรือสั่งเอง:
```powershell
docker compose up -d --build
```
ครั้งแรกใช้เวลาหลายนาที (ดาวน์โหลด LibreOffice) จากนั้นเปิด <http://localhost:8000> แล้วล็อกอินด้วยผู้ดูแลระบบตามที่ตั้งไว้ใน `.env`

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `docker compose ps` | ดูสถานะ (ต้องมี web, worker, db, redis) |
| `docker compose logs -f web worker` | ดู log |
| `docker compose down` | ปิดระบบ (ข้อมูลยังอยู่) |
| `docker compose up -d --build` | เปิดใหม่ / อัปเดตหลังได้โค้ดใหม่ (`git pull` ก่อน) |

> ห้ามใช้ `docker compose down -v` เพราะ `-v` จะลบฐานข้อมูลทิ้ง

### 1.6 ตั้งค่าครั้งแรก (เมนู "ตั้งค่า" ด้วยบัญชีผู้ดูแลระบบ)
1. **หน่วย:** ตรวจ "สถานที่นัด" และ "ที่อยู่ผู้ส่ง" ของ กก.1
   - **กรอกของ กก.2** เพราะแบบฟอร์มที่ได้มามีเฉพาะที่อยู่ กก.1
   - คดีของ กก.2 ออกหมายไม่ได้จนกว่าจะกรอก
2. **นำเข้าข้อมูล:** นำเข้าทะเบียนคดีและไฟล์ผู้แจ้ง (ดูข้อ 2)
3. **ผู้ลงนาม (พนักงานสอบสวน):** ตอนนำเข้าทะเบียน ระบบสร้างผู้ลงนามจากคอลัมน์ "พนักงานสอบสวน" ให้อัตโนมัติ
   - ชื่อที่ต่างกันแค่ช่องว่าง หรือมี/ไม่มีคำว่า "หญิง" นำหน้า ถือเป็นคนเดียวกัน และตัด "หญิง" ออกจากชื่อที่ใช้ลงนาม
   - ยศ ตำแหน่ง และโทรศัพท์ไม่มีในทะเบียน **ผู้ดูแลระบบนำเข้าจากไฟล์ Excel** ที่ ตั้งค่า → พนักงานสอบสวน → "นำเข้ายศ/ตำแหน่งจาก Excel" (เจ้าหน้าที่ outsource ไม่ต้องกรอก)
   - ระบบจับคู่แต่ละแถวในไฟล์กับพนักงานสอบสวนในทะเบียน **ด้วยชื่อ-นามสกุล** (ไม่สนช่องว่าง และคำว่า "หญิง" นำหน้า) แล้วดึงยศ ตำแหน่ง โทรศัพท์มาใส่
     - ใช้ไฟล์รายชื่อของหน่วยได้เลย หัวคอลัมน์ เช่น ชื่อ-สกุล / ยศ / ตำแหน่ง / โทรศัพท์ หรือแยกเป็น ชื่อ กับ นามสกุล คนละคอลัมน์ก็ได้
     - ชื่อที่ไม่มีในทะเบียนจะเพิ่มเป็นผู้ลงนามใหม่ หน้าตรวจสอบก่อนยืนยันจะบอกว่าแต่ละแถว "แก้ไข" "เพิ่มใหม่" หรือ "ไม่เปลี่ยน"
     - หรือกด "ดาวน์โหลดแบบฟอร์ม Excel" (มีชื่อทุกคนในทะเบียนแล้ว ช่องยศมีรายการให้เลือก) กรอกแล้วนำเข้า
     - ยศย่อแปลงเป็นยศเต็มให้ (พ.ต.ท. / พ.ต.ท / พ. ต. ท. เป็น พันตำรวจโท) และแยกยศออกจากชื่อได้ ถ้าอยู่ช่องเดียวกัน
     - เบอร์โทรที่ Excel ตัดเลข 0 หน้าออก ระบบเติมกลับให้
     - ช่องที่เว้นว่างไม่ลบค่าเดิม
   - ผู้ดูแลระบบยังแก้ยศ/ตำแหน่งรายคนได้ที่ ตั้งค่า → พนักงานสอบสวน หรือในหน้าออกหมาย
4. **สถานะคดี:** สถานะ "สิ้นสุด" เป็นสถานะสิ้นสุดเพียงตัวเดียวโดยค่าเริ่มต้น เปลี่ยนสถานะอื่นให้นับเป็นสิ้นสุดได้ (เช่น "ส่งสำนวนอัยการ")
5. **ผู้ใช้และสิทธิ์:** ระบบมีบทบาทผู้ใช้ 2 แบบเท่านั้น

| บทบาท | สิทธิ์ |
|---|---|
| ผู้ดูแลระบบ | ใช้งานได้ทุกส่วน: นำเข้า ทะเบียนคดี แก้สถานะ/ที่อยู่ ดูเลขบัตรเต็ม ออกหมาย ส่งออก มอบหมายงานโทร ตั้งค่า |
| เจ้าหน้าที่ติดต่อผู้เสียหาย (outsource) | คดีที่ยังไม่สิ้นสุดทุกคดี (รายการโทรรวม ไม่ต้องมอบหมาย): บันทึกผลการโทรพร้อมแนบไฟล์, แก้ที่อยู่, **เปลี่ยนสถานะคดี**, **ออกหมายเรียก** (ยศ/ตำแหน่งผู้ลงนามมาจากไฟล์ที่ผู้ดูแลนำเข้า), ดาวน์โหลดและส่งออกหมาย ไม่เห็นหน้าทะเบียนคดี การนำเข้า การตั้งค่า และเลขบัตรเต็ม |

ผู้ดูแลระบบลดสิทธิ์หรือปิดบัญชีของตัวเองไม่ได้ และระบบต้องมีผู้ดูแลระบบที่ใช้งานอยู่อย่างน้อย 1 คนเสมอ บัญชีหัวหน้า ธุรการ และพนักงานสอบสวนที่มีอยู่เดิม จะถูกเปลี่ยนเป็นผู้ดูแลระบบอัตโนมัติเมื่ออัปเดตระบบ

ผู้ลงนามในหมายคือพนักงานสอบสวนเจ้าของคดีเสมอ (จากข้อ 3) ไม่ใช่ผู้ใช้ที่กดออก ระบบบันทึกชื่อผู้กดออกไว้ในบันทึกการใช้งาน

### 1.7 ลองระบบด้วยข้อมูลสมมติ (เครื่องทดสอบเท่านั้น)
```powershell
docker compose exec web python manage.py load_demo
```
คำสั่งนี้สร้างผู้ใช้ทดลอง 2 บัญชี: `admin` (ผู้ดูแลระบบ) และ `call1` (outsource) รหัสผ่าน `demo12345` **ห้ามรันบนเครื่องใช้งานจริง**

### 1.8 ขึ้นเซิร์ฟเวอร์ (สำหรับผู้ดูแลเซิร์ฟเวอร์)
- รันด้วย `docker compose up -d --build` บนเซิร์ฟเวอร์ (ต้องมี service `web`, `worker`, `db`, `redis` ตาม `docker-compose.yml`)
- web ฟังที่พอร์ต `8000` (เปลี่ยนด้วย `WEB_PORT`) ให้วางหลัง reverse proxy ที่ทำ HTTPS และส่ง header `X-Forwarded-Proto`
  - ตั้งใน `.env`: `DJANGO_HTTPS=1`, `DJANGO_ALLOWED_HOSTS=<โดเมน>`, `DJANGO_CSRF_TRUSTED_ORIGINS=https://<โดเมน>`
  - ให้ proxy รับไฟล์อัปโหลดได้อย่างน้อย 30 MB (เช่น nginx `client_max_body_size 30m;`) และ timeout อย่างน้อย 300 วินาที (ส่งออกหลายร้อยฉบับ)
- volume ที่ต้องเก็บถาวรและสำรอง: `pgdata` (ฐานข้อมูล) และ `media` (ไฟล์แนบการโทร) — `appdata` เก็บแค่ตารางเวลางานเบื้องหลัง
- ไม่ต้องเปิดพอร์ตของ PostgreSQL/Redis ออกนอกเครื่อง (compose ไม่ได้เปิดไว้อยู่แล้ว)
- ห้ามรัน `load_demo` บนเซิร์ฟเวอร์จริง
- อัปเดต: `git pull` แล้ว `docker compose up -d --build` (migration รันให้เองตอน web เริ่ม)

## 2. การใช้งาน

### นำเข้าข้อมูล
เมนู **นำเข้าข้อมูล** มี 5 ขั้นตอน: อัปโหลด → เลือกชีต → จับคู่คอลัมน์ → ตรวจสอบ → ยืนยัน
- **ข้อมูลผู้แจ้ง:** ไฟล์จากระบบรับแจ้งความออนไลน์ (ชีต `Grid`)
- **ทะเบียนคดี:** ไฟล์ทะเบียนของกอง เลือกชีตปีที่ต้องการได้
- **จับคู่คอลัมน์:** ระบบจับคู่จากชื่อหัวตารางอัตโนมัติ ถ้าหัวตารางเปลี่ยน ให้เลือกเอง ระบบจะจำไว้ใช้ครั้งหน้า
- **หน้าตรวจสอบ:** แสดง เพิ่มใหม่ / อัปเดต / มีปัญหา / จับคู่กับอีกไฟล์ไม่ได้ และสรุปสิ่งที่เปลี่ยน เช่น "สถานะเปลี่ยน 12 คดี"
  - ยังไม่มีอะไรถูกบันทึกจนกว่าจะกดยืนยัน
- **นำเข้าซ้ำ:** อัปเดตแถวเดิมตามเลขรับแจ้ง ไม่สร้างซ้ำ (ระบบตัดช่องว่างและแปลงเป็นตัวพิมพ์ใหญ่ก่อนเทียบ)
- **แถวที่มีปัญหา** (ไม่มีบ้านเลขที่, ไม่มีตำบล/อำเภอ/จังหวัด, เลขรับแจ้งซ้ำในไฟล์, เลขบัตรไม่ใช่ 13 หลัก) ยังนำเข้าได้แต่ติดธงไว้ ดาวน์โหลดรายการเป็น Excel ได้
- **รหัสไปรษณีย์:** ระบบเติมให้จาก ตำบล + อำเภอ + จังหวัด แยกเก็บจากค่าเดิม (ข้อมูลจาก [kongvut/thai-province-data](https://github.com/kongvut/thai-province-data) MIT License ฝังในระบบแล้ว)
  - ตอนกรอก/แก้ที่อยู่ในหน้าคดี ระบบเติมรหัสไปรษณีย์ให้ทันทีที่พิมพ์ตำบล/อำเภอ/จังหวัด ถ้าพื้นที่มีหลายรหัสจะให้เลือก ถ้าบันทึกโดยเว้นช่องว่าง ระบบเติมให้ตอนบันทึก
  - ข้อมูลที่นำเข้าไว้แล้วเติมย้อนหลังด้วย `python manage.py fill_postcodes` (ระบบรันให้เองทุกครั้งที่เริ่ม)
  - ใช้ตารางรหัสไปรษณีย์ที่ฝังในระบบ ไม่ส่งข้อมูลไปที่บริการภายนอก
- **คดีที่จับคู่ไม่ได้:** นำเข้าได้ แต่ออกหมายไม่ได้จนกว่าจะจับคู่ได้หรือกรอกที่อยู่เอง เมื่อนำเข้าไฟล์ผู้แจ้งรอบใหม่ ระบบจับคู่ให้อัตโนมัติ
- **ผู้แจ้งที่ไม่อยู่ในทะเบียน:** เก็บไว้ แต่ไม่แสดงในทะเบียนคดี

### ทะเบียนคดีและรายละเอียดคดี
- ค้นหาและกรองได้ตามสถานะ ปี หน่วย พนักงานสอบสวน ประเภทคดี
- แท็บ **ยังไม่สิ้นสุด / สิ้นสุดแล้ว / ทั้งหมด** พร้อมจำนวนคดี และเรียงตามวันที่รับแจ้ง (ใหม่→เก่า หรือ เก่า→ใหม่) หรือตามเวลาแก้ไขล่าสุด
- แก้สถานะได้จากช่องสถานะในแต่ละแถวโดยตรง ระบบบันทึกเวลาและผู้แก้ไว้
- ปุ่มลัด: ยังไม่สิ้นสุด / ที่อยู่ไม่ครบ / จับคู่ไม่ได้ / ยังไม่เคยออกหมาย
- **ส่งออก Excel** ได้คอลัมน์เดิม แยกชีตตามชีตต้นทาง
- **แก้ที่อยู่ในหน้าคดี:** ระบบเก็บที่อยู่ที่แก้แยกไว้และใช้ที่อยู่นี้ก่อนเสมอ ไฟล์ผู้แจ้งรอบใหม่จะไม่ทับ
  - ถ้าที่อยู่ในไฟล์ใหม่เปลี่ยนไป ระบบจะเตือนให้เลือกว่าจะใช้อันไหน
- **เลขบัตรประชาชน:** แสดงแบบ `x-xxxx-xxxxx-12-3` ผู้มีสิทธิ์กด "แสดง" ได้ และระบบบันทึกทุกครั้งที่กดดู

### ออกหมายเรียก
1. ในทะเบียนคดี ติ๊กเลือกคดี แล้วกด **ออกหมายเรียก (n รายการ)** หรือ "ออกหมายทุกคดีที่ตรงตัวกรอง"
2. ตั้งค่าหมาย:
   - วันนัดเริ่มต้น = วันออกหมาย + 14 วัน (ตรงเสาร์/อาทิตย์เลื่อนเป็นวันจันทร์) เวลา 09.00 น.
   - เลือก "ไล่เวลาทีละ 30 นาที" ได้ (ไล่แยกตามพนักงานสอบสวน)
3. ระบบจัดกลุ่มตามผู้ลงนาม และตรวจข้อความที่ ป.วิ.อ. มาตรา 53 กำหนด รายการที่ไม่ครบจะแสดงเหตุผลและไม่ถูกออกหมาย
4. กด **ดูตัวอย่าง PDF** เพื่อตรวจ แล้วกด **ยืนยันออกหมาย**
   - ตัวเลือก "เปลี่ยนสถานะคดีเป็น 'ออกหมายเรียก'" ค่าเริ่มต้นไม่ติ๊ก
5. ระบบพาไปหน้า **ส่งออก**:
   - เลือก PDF / Word / ทั้งสองแบบ
   - เลือกแยกไฟล์รายคน (ค่าเริ่มต้น: 1 คน = 1 ไฟล์ ชื่อ `เลขรับแจ้ง_ชื่อ` มีหมายเรียกตามด้วยซอง) หรือรวมทุกคนเป็นไฟล์เดียว
   - เลือกพิมพ์ใบจ่าหน้าซองพร้อมกันได้
   - เกิน 20 ฉบับจะทำงานเบื้องหลังและแสดงความคืบหน้า
6. กด **เปิดดู / พิมพ์** เพื่อดู PDF ในหน้าเว็บ
   - เลือกรายคนจากรายการด้านซ้าย แล้วกด **พิมพ์** หรือกด **พิมพ์ทั้งหมด** เพื่อพิมพ์ทุกคนในครั้งเดียว
   - หมายเรียกแต่ละฉบับเปิดดูและพิมพ์ได้จากปุ่ม "ดู / พิมพ์" ในรายการหมายเรียก หน้าคดี และหน้าบันทึกผลการโทร
   - ถ้าปุ่มพิมพ์ใช้ไม่ได้ในเบราว์เซอร์บางตัว ให้กด "เปิดแท็บใหม่" แล้วสั่งพิมพ์จากแท็บนั้น
7. **ใส่เลข EMS** เมื่อส่งไปรษณีย์แล้ว เพื่อยืนยันว่าส่งจริง
   - **ยิงบาร์โค้ด EMS:** ในหน้า "หมายเรียกที่ออก" กด **ยิงบาร์โค้ด EMS** เลือกหมายจากรายการ "ยังไม่มีเลข EMS" (หรือพิมพ์ "เลขรับแจ้ง-ครั้งที่" เช่น C660611953-1) แล้วยิงบาร์โค้ด EMS ระบบบันทึกทันทีและเลือกฉบับถัดไปให้ (มีเสียงเตือนเมื่อสำเร็จ/ผิดพลาด) ครบแล้วกด **พิมพ์ซองของรายการนี้**
   - **หน้าซอง:** บาร์โค้ดบนซองคือเลข EMS ของฉบับนั้น พร้อมตัวเลขใต้บาร์โค้ดไว้ตรวจด้วยตา ซองที่พิมพ์ก่อนยิงเลข EMS จะมีแต่ช่องว่าง "EMS ......" (ไม่มีบาร์โค้ด) จึงควรยิงเลข EMS ก่อนพิมพ์ซอง
   - **ตรวจซอง:** ในหน้ายิงบาร์โค้ด ยิงบาร์โค้ด EMS บนซองที่พิมพ์แล้ว (โดยยังไม่เลือกหมาย) ระบบบอกว่าเลขนั้นเป็นของคดีไหน ชื่อใคร เพื่อเทียบกับชื่อบนซอง
   - บนซองมีบรรทัด "เลขที่หนังสือ: … ลงวันที่: (วันที่ออกหมาย)" ตั้งเลขที่หนังสือได้ที่ ตั้งค่า → ระบบ
   - ในหน้า "หมายเรียกที่ออก" พิมพ์หรือยิงบาร์โค้ดเลข EMS ในช่องของแต่ละฉบับ แล้วกด Enter ระบบจะเลื่อนไปช่องถัดไปให้ ใส่ได้จากหน้าบันทึกผลการโทรและหน้าคดีด้วย
   - หลายรายการพร้อมกัน: กด **บันทึกเลข EMS หลายรายการ** แล้ววาง "เลขรับแจ้ง เลข EMS" บรรทัดละ 1 ฉบับ (คัดลอก 2 คอลัมน์จาก Excel ได้)
   - ระบบตรวจรูปแบบและเลขตรวจสอบตามมาตรฐานไปรษณีย์ (เช่น EB123456785TH) และไม่ยอมให้ใช้เลขเดียวกันกับ 2 ฉบับ
   - บันทึกว่าใครใส่เมื่อไรไว้ในบันทึกการใช้งาน กดที่เลขเพื่อเปิดหน้าติดตามพัสดุของไปรษณีย์ไทย กรองดูได้ว่า "ยังไม่มีเลข EMS" หรือ "ส่งแล้ว"
8. บันทึกผลหมาย (มาตามนัด / ไม่มา / ยกเลิก) ได้ในหน้ารายละเอียดคดี

ไฟล์ที่ส่งออกถูกลบอัตโนมัติหลัง N วัน (ตั้งในเมนู ตั้งค่า → ระบบ) หมายเรียกที่ไฟล์ถูกลบแล้วสร้างใหม่ได้เหมือนเดิมทุกตัวอักษร เพราะระบบเก็บค่าที่ใช้ไว้

### ติดต่อผู้เสียหายทางโทรศัพท์ (เจ้าหน้าที่ outsource)

**1. สร้างบัญชีผู้โทร:** ไปที่ ตั้งค่า → ผู้ใช้และสิทธิ์ แล้วเลือกบทบาท **"เจ้าหน้าที่ติดต่อผู้เสียหาย (outsource)"**
- บัญชีนี้เปิดได้แค่หน้ารายการโทร หน้าบันทึกผล และหน้าออกหมาย/ส่งออก ไม่เห็นหน้าทะเบียนคดี และเลขบัตรประชาชนเต็ม

**ใช้เฉพาะ กก.1:** ตอนนำเข้าทะเบียน ระบบนำเข้าเฉพาะคดีที่คอลัมน์ "หน่วยที่รับผิดชอบ" เป็น กก.1 บก.สอท.4 (ตั้งค่า `OWN_UNIT` ใน `.env`)
- คดีของหน่วยอื่น (เช่น กก.2) ไม่ถูกนำเข้า หน้าตรวจก่อนนำเข้าบอกจำนวนที่ข้าม
- ถ้าในระบบมีคดีของหน่วยอื่นจากการนำเข้าครั้งก่อน หน้าแรกของผู้ดูแลจะแจ้งเตือน นำเข้าไฟล์ทะเบียนอีกครั้งแล้วระบบจะเอาออก (แจ้งจำนวนและบันทึกการโทรที่จะหายก่อนกดยืนยัน) ยกเว้นคดีที่ออกหมายเรียกไปแล้ว ซึ่งเก็บไว้เสมอ

**อัปเดตทุกสัปดาห์จากระบบใหญ่ และรายงานส่งกลับ**
1. **นำเข้าข้อมูล** → เลือก **"อัปเดตจากระบบใหญ่ (ไฟล์รายสัปดาห์)"** → เลือกไฟล์ที่ส่งออกจากระบบใหญ่ (ชีต Grid ทุกหน่วยของ บก.สอท.4)
   - คดีที่มีอยู่แล้ว: อัปเดตสถานะ อายุ เลขคดีอาญา พนักงานสอบสวน ฯลฯ ช่องที่ไฟล์เว้นว่างคงค่าเดิม ไม่แตะบันทึกการติดต่อและผลการโทร (ไฟล์นี้มักไม่ระบุหน่วย ระบบจึงดูจากเลขรับแจ้งที่มีอยู่แล้ว)
   - คดีใหม่: เพิ่มเฉพาะแถวที่หน่วยเป็น กก.1 · แถวอื่นไม่นำเข้า · ไม่ลบคดีใด
   - ชื่อพนักงานสอบสวนที่มียศนำหน้า (พ.ต.ต.ชื่อ) ถือเป็นคนเดียวกับชื่อในทะเบียน ผู้ลงนามที่ยังไม่มียศจะได้ยศจากไฟล์นี้
   - ถ้าเผลอเลือกประเภท "ทะเบียนคดี" กับไฟล์นี้ ระบบจะเตือนและไม่ให้ยืนยัน
2. เมนู **แก้สถานะระบบใหญ่**: รายการ "ตรวจสอบการอัปเดตสถานะสิ้นสุด" คือคดีที่ผู้เสียหายไม่ประสงค์ดำเนินคดี (ผลการโทรในระบบ หรือบันทึกการติดต่อในทะเบียน) แต่สถานะล่าสุดจากระบบใหญ่ยังไม่เป็นสิ้นสุด
   - ดาวน์โหลด **PDF** (A4 แนวตั้ง แบบเดียวกับแบบฟอร์มของหน่วย) หรือ **Excel** · ติ๊ก "ไม่รวม …" เพื่อเอาบางสถานะออก (เช่น ส่งสำนวนอัยการ)
   - วันที่แจ้งไม่ประสงค์: วันที่โทรในระบบ หรือวันที่ที่เขียนต่อจากคำว่าไม่ประสงค์ในบันทึกการติดต่อ (ถ้าไม่ได้เขียนวันที่ไว้ ช่องจะว่าง)
3. สัปดาห์ถัดไปนำเข้าไฟล์ใหม่ คดีที่แก้แล้วจะหายจากรายการเอง

**2. รายการโทรรวม (ไม่ต้องมอบหมาย):** คดีที่ยังไม่สิ้นสุดทุกคดีขึ้นในรายการโทรเองหลังนำเข้าทะเบียน เจ้าหน้าที่ทุกคนเห็นรายการเดียวกัน
- คนที่บันทึกผลการโทรคดีไหนก่อน จะเป็น "ผู้รับผิดชอบ" คดีนั้น (คนอื่นยังโทรต่อได้ แต่ผู้รับผิดชอบไม่เปลี่ยน)
- กันโทรซ้ำ: ถ้ามีคนเปิดคดีอยู่ คนอื่นจะเห็นป้าย "กำลังเปิดอยู่" ในรายการ และคำเตือนในหน้าบันทึกผล ปุ่ม "คดีถัดไป" จะข้ามคดีนั้นไป (ป้ายหายเองหลัง 10 นาที หรือเมื่อบันทึกผลแล้ว)
- การโทรก่อนมีระบบนับจากคอลัมน์ "บันทึกการติดต่อ" ในไฟล์ทะเบียน: มีข้อความ = **โทรแล้ว**, ข้อความว่า "(ไม่)ประสงค์ดำเนินคดี" / "ติดต่อได้" / "ติดต่อแล้ว" = **ติดต่อได้** เมื่อบันทึกการโทรในระบบแล้ว ระบบใช้ผลการโทรล่าสุดในระบบแทน
- **ภาพรวมการโทร (ตัวเลขชุดเดียวทั้งระบบ):** ทุกการแยกบวกกันได้พอดี และตัวเลขทุกตัวเท่ากับจำนวนรายการที่กดเปิดได้
  - **ทั้งหมด** = **โทรเสร็จสิ้น** + **ยังไม่ได้โทร** (โทรเสร็จสิ้น = มีการโทรในระบบ หรือมีบันทึกการติดต่อในไฟล์ทะเบียน สถานะคดีไม่ได้ใช้ตัดสินว่าโทรแล้ว)
  - **โทรเสร็จสิ้น** = **ติดต่อได้** + **ติดต่อไม่ได้** (รวมที่โทรแล้วแต่ไม่ได้จดผล)
  - **ติดต่อได้** = **ประสงค์ดำเนินคดี** + **ไม่ประสงค์ดำเนินคดี** (+ ยังไม่ระบุ ถ้ามี) · ไม่ประสงค์ไม่ต้องออกหมายเรียก
  - **ติดต่อไม่ได้** = **รอออกหมายเรียก** + **ออกหมายเรียกแล้ว** (+ คดีที่สถานะสิ้นสุดแล้ว ซึ่งไม่ต้องออกหมาย)
- ด้านบนมีกล่องสรุป 4 กล่องและแผนภาพ Sankey ของตัวเลขชุดเดียวกัน กดที่กล่องหรือแถบเพื่อดูรายการ
- แท็บ: ทั้งหมด / โทรเสร็จสิ้น / ติดต่อได้ / ประสงค์ดำเนินคดี / ไม่ประสงค์ดำเนินคดี / ติดต่อไม่ได้ / รอออกหมายเรียก / ออกหมายเรียกแล้ว / ยังไม่ได้โทร
- ในแท็บ "ติดต่อไม่ได้" กด **ออกหมายเรียกทุกคดีที่รอออกหมาย** เพื่อส่งทุกคดีในกลุ่มนี้ (ตามคำค้น/ตัวกรอง ครั้งละไม่เกิน 1,000 คดี) ไปหน้าออกหมายเรียก คดีที่สิ้นสุดแล้วหรือไม่ประสงค์ดำเนินคดี ระบบไม่ให้ออกหมาย แม้ติ๊กเลือกเอง
- "สิ้นสุด" ในหน้าสถิติและทะเบียนคดี = สถานะคดีสิ้นสุด หรือ ไม่ประสงค์ดำเนินคดี (เช่น สิ้นสุด = ไม่ประสงค์ + สถานะสิ้นสุดอื่นๆ)
- "ประสงค์" = ผลการโทร "นัดเข้าพบพนักงานสอบสวน" หรือ "ให้ข้อมูลเพิ่มเติมแล้ว" หรือไฟล์ทะเบียนเขียนว่า "ประสงค์ดำเนินคดี" · "ไม่ประสงค์" = ผล "ไม่ประสงค์ดำเนินคดีต่อ" หรือไฟล์เขียนว่า "ไม่ประสงค์"
- กรองตาม "ผลการโทร" (ติดต่อได้ / ติดต่อไม่ได้ / รายผล) และค้นหาเลขรับแจ้ง ชื่อ เบอร์ได้ ตัวกรองค้างไว้เมื่อเปลี่ยนแท็บ
- **ปีที่รับแจ้ง / สถานะคดี:** เลือกปี และเลือก ยังไม่สิ้นสุด / สิ้นสุดแล้ว / สถานะเจาะจง (ตัวเลขทั้งหน้านับตามที่เลือก) ระบบจำไว้จนกด **ล้างตัวกรอง**
- **นัดเข้าพบพนักงานสอบสวน:** ใส่วันเวลานัดหรือเว้นว่างไว้ก็ได้ มีปุ่มลัด พรุ่งนี้ 09:00 / อีก 3 วัน / อีก 7 วัน (เลื่อนไปวันทำการ)
- **เรียงตาม (ปุ่ม กดซ้ำเพื่อสลับทิศ):** ลำดับงานโทร (ค่าเริ่มต้น) · มูลค่าความเสียหาย น้อย → มาก / มาก → น้อย · วันที่รับแจ้ง (คดีที่ไม่มีมูลค่าหรือวันที่อยู่ท้ายสุด) ทะเบียนคดีเรียงตามมูลค่าได้เช่นกัน · ระบบจำการเรียงที่เลือกไว้ของแต่ละคน กดเข้าคดีแล้วกลับมาก็ยังเรียงเหมือนเดิม และ "บันทึก แล้วไปคดีถัดไป" / "ข้ามไปคดีถัดไป" ไปแถวถัดไปของรายการที่กำลังดูอยู่ (แท็บ คำค้น ปี สถานะคดี และการเรียงเดียวกัน) · กดเรียงหรือเปลี่ยนตัวกรองแล้วหน้าอยู่ตำแหน่งเดิม ไม่เด้งขึ้นบน
- ปุ่ม "บันทึก แล้วไปคดีถัดไป" เลือกคดีที่ยังไม่สิ้นสุดและยังต้องโทร (ไม่รวมนัดโทรกลับที่ยังไม่ถึงเวลา และคดีที่ติดต่อได้แล้ว)
- ผู้ดูแลระบบยังกำหนดผู้รับผิดชอบล่วงหน้าได้ (ไม่บังคับ) ที่ ติดต่อผู้เสียหาย → กำหนดผู้รับผิดชอบ หรือติ๊กคดีในทะเบียนแล้วกด **มอบหมายให้โทร**

**3. ผู้โทรบันทึกผล:** เปิดรายการที่ต้องโทร → กดเบอร์เพื่อโทร → เลือกผล → กด **"บันทึก แล้วไปคดีถัดไป"**
- ผู้โทรออกหมายเรียกเองได้: กด "ออกหมายครั้งที่ n" ในหน้าบันทึกผลการโทร หรือติ๊กหลายคดีในรายการโทรแล้วกด "ออกหมายเรียก" ผู้โทรไม่ต้องกรอกยศ/ตำแหน่ง: ถ้าผู้ลงนามยังไม่มีข้อมูล คดีนั้นจะขึ้นว่ารอผู้ดูแลนำเข้าไฟล์ยศ/ตำแหน่ง และออกหมายได้ทันทีเมื่อนำเข้าแล้ว ผู้ลงนามยังเป็นพนักงานสอบสวนเจ้าของคดีเสมอ และระบบบันทึกว่าใครเป็นคนกดออก
- **แนบไฟล์:** แนบรูปแชท สลิป ไฟล์เสียงสนทนา หรือเอกสาร ได้ตอนบันทึกผล (เลือกได้หลายไฟล์) หรือกด "แนบไฟล์เพิ่ม" ใต้การโทรครั้งก่อนในประวัติการโทร
  - ไฟล์ละไม่เกิน 25 MB (ตั้งได้ด้วย `CALL_ATTACHMENT_MAX_MB` ใน `.env`) รองรับ รูปภาพ, PDF, Word, Excel, ไฟล์เสียง, วิดีโอ, ZIP
  - เห็นได้เฉพาะผู้ใช้ที่ล็อกอิน (ผู้ดูแลและเจ้าหน้าที่ outsource) ลบได้เฉพาะคนที่แนบหรือผู้ดูแล ทุกครั้งที่แนบ/ลบบันทึกใน AuditLog
  - ไฟล์แนบไม่ถูกลบอัตโนมัติ (ต่างจากไฟล์ที่ส่งออก) และสำรองไปพร้อมฐานข้อมูล (ข้อ 4)
- **เปลี่ยนสถานะคดี:** เลือกสถานะใหม่ในกล่อง "เปลี่ยนสถานะคดี" ในหน้าบันทึกผล พร้อมใส่เหตุผลได้ ระบบบันทึกว่าใครเปลี่ยนเมื่อไร
- ผู้โทรแก้หรือกรอกที่อยู่ได้ในกล่อง **"ที่อยู่สำหรับออกหมาย"** ในหน้าบันทึกผลการโทร (เช่น ผู้เสียหายบอกบ้านเลขที่ทางโทรศัพท์) ใส่ตำบล/อำเภอ/จังหวัดแล้วระบบเติมรหัสไปรษณีย์ให้ ที่อยู่นี้ใช้ออกหมายทันที ไม่ถูกทับเมื่อนำเข้าไฟล์ใหม่ และบันทึกว่าใครแก้เมื่อไรไว้ใน AuditLog

| ผลที่เลือกได้ | ผลต่องานโทร |
|---|---|
| ติดต่อได้ – นัดเข้าพบพนักงานสอบสวน (ต้องระบุวันเวลานัด) / ให้ข้อมูลเพิ่มเติมแล้ว / ไม่ประสงค์ดำเนินคดีต่อ / อื่นๆ | งานโทรคดีนั้นเสร็จ |
| ติดต่อได้ – ขอให้โทรกลับภายหลัง (ต้องระบุเวลา) | ซ่อนจากแท็บ "ต้องโทร" จนถึงเวลานัด |
| ติดต่อไม่ได้ – ปิดเครื่อง / ไม่รับสาย / สายไม่ว่าง / ฝากข้อความไว้ | ยังอยู่ในรายการต้องโทร (ระบุเวลาโทรกลับได้) |
| ปลายทางแจ้งว่าไม่รู้จักผู้เสียหาย / เบอร์ไม่ถูกต้อง | งานโทรเสร็จ (เปิดใหม่ได้ในหน้าบันทึกผล) |

**4. ติดตามผล:**
- หน้า "ติดต่อผู้เสียหาย" แสดงความคืบหน้าแยกตามผู้โทร
- **ส่งออกผลการโทร (Excel)** ได้ทุกครั้งที่โทร
- ในทะเบียนที่ส่งออก คอลัมน์ "บันทึกการติดต่อ" จะต่อท้ายผลจากระบบในรูปแบบเดิม เช่น `ครั้งที่ 1 ไม่สามารถติดต่อได้ (ปิดเครื่อง) 9 ตค 69 เวลา 10.30 น.`
- การบันทึกผลทุกครั้งเก็บใน AuditLog และแสดงในหน้ารายละเอียดคดี

### สถิติ
เมนู **สถิติ** (ผู้ดูแลระบบและเจ้าหน้าที่ outsource)
- เลือกช่วงเวลา: 7 วัน / 30 วัน / 90 วัน / เดือนนี้ / ปีนี้ หรือกำหนดวันเอง (ย้อนหลังได้สูงสุด 1 ปีต่อครั้ง)
- ตัวเลขในช่วงที่เลือก: จำนวนการโทร ติดต่อได้ / ไม่ได้ (และอัตรา) นัดเข้าพบ พงส. หมายเรียกที่ออก และเลข EMS ที่บันทึก
- **ความคืบหน้า** (บนสุด): ยอดคดีทั้งหมดเป็นฐาน แยกเป็น **สิ้นสุด / ยังไม่สิ้นสุด** กราฟเส้นคดียังไม่สิ้นสุดรายวันเทียบกับเส้นยอดทั้งหมด ช่วงที่เลือกสิ้นสุดเพิ่มกี่คดี เร็วหรือช้ากว่าช่วงก่อนหน้า และถ้าเร็วเท่านี้อีกกี่วันจะครบ
  - **สิ้นสุด** = สถานะคดีสิ้นสุด หรือ **ไม่ประสงค์ดำเนินคดี** (ผลการโทรล่าสุดในระบบ หรือบันทึกการติดต่อในทะเบียนถ้ายังไม่มีการโทรในระบบ) ใช้หลักเดียวกันทั้งระบบ: แท็บ ยังไม่สิ้นสุด / สิ้นสุดแล้ว ในรายการที่ต้องโทรและทะเบียนคดี
- กราฟเส้นรายวัน (ชี้ที่กราฟเพื่อดูตัวเลขของวันนั้น) และแผนภาพ Sankey ของภาพรวม ผลการโทรแยกตามประเภท ผลงานรายเจ้าหน้าที่ และตารางรายวันย้อนหลัง
- ภาพรวมทั้งหมด ณ ขณะนี้: คดีทั้งหมด โทรแล้ว ยังไม่ได้โทร ต้องโทร ติดต่อได้แล้ว หมายเรียกส่งแล้ว / ยังไม่ส่ง
- กด **ส่งออก Excel** ได้ทั้งตารางรายวันและรายเจ้าหน้าที่

### สรุปผลประจำวันและข้อความลงบันทึกประจำวัน
เมนู **สรุปผลประจำวัน** (หรือปุ่มบนหน้ารายการที่ต้องโทร) ทุกบทบาทใช้ได้ ใช้แทนการพิมพ์รายงานเองทุกวัน
- สรุปเป็นรายวัน: เลือกวันที่ (ค่าเริ่มต้นวันนี้) และเลือกผู้โทรเฉพาะคนได้
- นับเฉพาะคดีที่โทรในวันนั้น จากผลการโทรที่บันทึกในระบบ คดีที่โทรหลายครั้งในวันเดียวนับครั้งเดียวตามผลการโทรครั้งสุดท้ายของวัน
  - ไม่ประสงค์ดำเนินคดี = "ไม่ประสงค์ดำเนินคดีต่อ"
  - ประสงค์ดำเนินคดีต่อ = "นัดเข้าพบพนักงานสอบสวน" และ "ให้ข้อมูลเพิ่มเติมแล้ว"
  - ไม่สามารถติดต่อได้ = ไม่รับสาย ปิดเครื่อง สายไม่ว่าง ฝากข้อความ ปลายทางไม่รู้จัก เบอร์ไม่ถูกต้อง
  - ข้อ 4 "ยังไม่ได้ข้อยุติ" (ขอให้โทรกลับ / อื่นๆ) ขึ้นเฉพาะวันที่มี เพื่อให้ยอดรวมตรงกับจำนวน Case ID
- **ข้อความรายงานผู้บังคับบัญชา** ("เรียนผู้บังคับบัญชาเพื่อโปรดทราบ ...") มีแต่ตัวเลข กด **คัดลอกข้อความ** แล้ววางใน LINE
- **ข้อความลงบันทึกประจำวัน** ("วันนี้( 9 พ.ย.69) พนักงานสอบสวน ...") รายชื่อเฉพาะคดีที่ไม่ประสงค์ดำเนินคดี พร้อมเลขรับแจ้งและเบอร์โทร
- ไฟล์ Word รูปแบบเดียวกับที่เจ้าหน้าที่ทำเอง: **ลงบันทึกประจำวัน 9.11.2569.docx** (รายชื่อไม่ประสงค์ฯ) และ **สรุปข้อมูลคดี 9.11.2569.docx** (ทุกคดีที่โทรในวันนั้น: เลขรับแจ้ง มูลค่า พนักงานสอบสวน เบอร์ บันทึกการติดต่อ)

### บอท LINE (ไม่บังคับ ปิดไว้โดยค่าเริ่มต้น)
ส่งข้อความรายงานผู้บังคับบัญชาเข้ากลุ่ม LINE อัตโนมัติวันละครั้ง **ส่วนนี้เป็นส่วนเดียวที่ส่งข้อมูลออกนอกเครื่อง** (ไปที่เซิร์ฟเวอร์ของ LINE) จึงส่งเฉพาะตัวเลขโดยค่าเริ่มต้น
1. สร้าง LINE Official Account และ Channel แบบ Messaging API ที่ developers.line.biz
2. ผู้ดูแลระบบไปที่ **ตั้งค่า → บอท LINE** ใส่ **Channel secret** (Basic settings) และ **Channel access token (long-lived)** (Messaging API → Issue) แล้วกด **บันทึกและทดสอบการเชื่อมต่อ**
   - รหัสเก็บในฐานข้อมูลของระบบ ไม่อยู่ใน git และไม่แสดงซ้ำหลังบันทึก ไม่ต้องแก้ไฟล์บนเซิร์ฟเวอร์
   - หรือใส่ใน `.env` (`LINE_CHANNEL_SECRET=` / `LINE_CHANNEL_ACCESS_TOKEN=`) แทนก็ได้ ถ้ามีใน `.env` จะใช้ค่านั้นก่อน
3. ใน LINE Developers ตั้ง Webhook URL เป็น `https://<โดเมนของระบบ>/line/webhook/` เปิด Use webhook และ Allow bot to join group chats
4. เชิญบอทเข้ากลุ่ม แล้วผู้ดูแลระบบไปที่ **ตั้งค่า → บอท LINE** กด **ใช้กลุ่มนี้** (บอทส่งเฉพาะกลุ่มที่ยืนยันแล้ว)
   - ถ้าเชิญบอทเข้ากลุ่มไว้ก่อนตั้ง Webhook เสร็จ ให้พิมพ์ข้อความอะไรก็ได้ในกลุ่ม 1 ครั้ง กลุ่มจะขึ้นให้ยืนยันเหมือนกัน
   - ผู้สร้างบัญชีควรเพิ่มพี่เลี้ยง/ผู้ดูแลระบบเป็น Admin ทั้งใน LINE Official Account Manager และใน Channel ของ LINE Developers เพื่อให้หน่วยดูแลบอทต่อได้
5. เปิด **ส่งอัตโนมัติ** และตั้งเวลา (ค่าเริ่มต้น 18:00) งานเบื้องหลังตรวจทุก 5 นาที ส่งวันละครั้ง วันที่ไม่มีการโทรไม่ส่ง
   - ติดตั้งแบบไม่มี Docker/Celery: ตั้ง cron หรือ Task Scheduler ให้รัน `python manage.py send_line_report --if-due` ทุก 5-10 นาที
- **โควตา:** ข้อความที่บอทส่งเข้ากลุ่มเองนับตาม**จำนวนสมาชิกในกลุ่ม** (กลุ่ม 15 คน ส่ง 1 ครั้ง = 15 ข้อความ) ส่วนการตอบคำสั่งที่พิมพ์ในกลุ่มไม่นับโควตา
  - `สรุป` = วันนี้, `สรุปเมื่อวาน`, `สรุป 9/11` = วันที่ 9 เดือน 11
  - ดูโควตาที่ใช้ไปได้ที่หน้าตั้งค่า → บอท LINE
- ติ๊ก **ส่งรายชื่อผู้ไม่ประสงค์ดำเนินคดี** เฉพาะเมื่อผู้บังคับบัญชาอนุญาต (ชื่อ เลขรับแจ้ง เบอร์โทรจะอยู่บนเซิร์ฟเวอร์ของ LINE)
- ทดสอบโดยไม่ส่งจริง: `python manage.py send_line_report --print`

### ล้างข้อมูลเพื่อเริ่มทดลองใหม่
ตั้งค่า → **ล้างข้อมูล** (เฉพาะผู้ดูแลระบบ) เลือกได้ 4 แบบ
- **ลบบันทึกการโทรของวันนี้ / ทั้งหมด:** ลบผลการโทรและไฟล์แนบของการโทรนั้น คดีกลับเป็นเหมือนก่อนโทร (บันทึกการติดต่อจากไฟล์ทะเบียนยังอยู่) ผู้ดูแลกด "รีเซ็ต" ใต้ตัวเลข "โทรวันนี้" ในหน้ารายการโทรเพื่อมาที่ตัวเลือกนี้ได้เลย ตัวเลข "โทรวันนี้" กลับเป็น 0 เองทุกเที่ยงคืนอยู่แล้ว
- **ลบเฉพาะหมายเรียกที่ออก:** ลบหมายเรียกและงานส่งออกทั้งหมด เก็บคดี ข้อมูลผู้แจ้ง และบันทึกการโทรไว้ ออกหมายใหม่ได้ทันที (ครั้งที่เริ่มจาก 1) และเลือกคืนสถานะคดีที่ระบบเปลี่ยนเป็น "ออกหมายเรียก" ตอนออกหมาย กลับเป็นสถานะเดิมจากไฟล์ได้
- **ลบข้อมูลคดีทั้งหมด:** ลบคดี ข้อมูลผู้แจ้ง หมายเรียก งานส่งออก บันทึกการโทร ไฟล์แนบ และประวัติการนำเข้าทั้งหมด แล้วนำเข้าใหม่ตั้งแต่ต้น
- เก็บไว้: ผู้ใช้ พนักงานสอบสวน (ยศ ตำแหน่ง) หน่วย สถานะคดี แบบฟอร์ม การตั้งค่า และบันทึกการใช้งาน
- ต้องพิมพ์คำว่า "ลบข้อมูลทั้งหมด" ใส่ชื่อ-นามสกุลผู้ลบ และรหัสผ่านของตัวเอง ระบบบันทึกชื่อผู้ลบ บัญชี เวลา และจำนวนข้อมูลที่ลบไว้ในบันทึกการใช้งาน
- ลบแล้วกู้คืนจากหน้าเว็บไม่ได้ ถ้าอาจต้องใช้ข้อมูลเดิม ให้สำรองข้อมูลก่อน (ข้อ 4)

### โลโก้หน่วย
ตั้งค่า → ระบบ → **โลโก้หน่วย** อัปโหลดรูป PNG / JPG / WebP (ไม่เกิน 2 MB แนะนำสี่เหลี่ยมจัตุรัส พื้นหลังโปร่งใส)
- ใช้ที่แถบเมนู หน้าเข้าสู่ระบบ และไอคอนแท็บเบราว์เซอร์
- เก็บในฐานข้อมูล จึงสำรองไปพร้อมฐานข้อมูลและไม่หายเมื่อล้างข้อมูล

### แก้ไขสถานะคดี
- ผู้ดูแลระบบแก้ได้ในหน้ารายละเอียดคดี หรือเลือกหลายคดีในทะเบียนแล้วเลือก "เปลี่ยนสถานะเป็น…"
- เจ้าหน้าที่ outsource แก้ได้ในหน้าบันทึกผลการโทร
- ถ้านำเข้าไฟล์ทะเบียนที่ยังระบุสถานะเดิม ระบบจะคงสถานะที่แก้ไว้ ถ้าไฟล์ระบุสถานะใหม่ ระบบจะใช้ค่าจากไฟล์

## 4. สำรองและกู้คืนข้อมูล

ข้อมูลอยู่ใน Docker volume 2 ส่วน:
- `pgdata`: ฐานข้อมูล
- `media`: ไฟล์แนบการโทร (`call_attachments/`) ไฟล์ที่อัปโหลดและไฟล์ที่ส่งออก

**สิ่งที่ต้องสำรองทุกวันคือฐานข้อมูลและไฟล์แนบการโทร** สคริปต์สำรองเก็บทั้งสองอย่าง ส่วนไฟล์ส่งออก/หมายเรียกสร้างใหม่ได้

### สำรอง
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\backup.ps1
```
สคริปต์จะสร้าง 2 ไฟล์ใน `C:\ccid4-backup\` และลบไฟล์สำรองที่เก่ากว่า 30 วัน
- `summons_ปีเดือนวัน_เวลา.dump`: ฐานข้อมูล
- `summons_ปีเดือนวัน_เวลา_files.tgz`: ไฟล์แนบการโทร

Linux: `tools/backup.sh /backup/ccid4 30` (ใส่ใน cron ได้ เช่น `0 2 * * * /opt/ccid4/tools/backup.sh /backup/ccid4`)
(ไม่ใช้ `pg_dump > ไฟล์` ใน PowerShell เพราะ PowerShell จะแปลงข้อมูลจนไฟล์เสีย)

**สำรองอัตโนมัติทุกวัน:** เปิด Task Scheduler → Create Basic Task → Daily แล้วตั้งค่าดังนี้
- Action: Start a program
- Program: `powershell.exe`
- Arguments: `-NoProfile -ExecutionPolicy Bypass -File C:\ccid4\tools\backup.ps1`

ควรคัดลอกไฟล์สำรองทั้ง 2 ไฟล์ไปเก็บอีกที่หนึ่งด้วย (เช่น ฮาร์ดดิสก์ภายนอกที่เข้ารหัส) เพราะเป็นข้อมูลส่วนบุคคล

### กู้คืน
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\restore.ps1 -File C:\ccid4-backup\summons_20260209_0200.dump
```
สคริปต์จะถามยืนยัน แล้วหยุด web/worker กู้คืนฐานข้อมูล เปิดกลับ และกู้ไฟล์แนบจาก `_files.tgz` ที่อยู่คู่กันให้เอง

Linux: `tools/restore.sh /backup/ccid4/summons_20260209_0200.dump`

- **ห้าม commit ไฟล์ข้อมูลจริงเข้า git:** `.gitignore` กันไฟล์ `*.xlsx` นอก `sample_data/`, `*.doc`, `data/`, `media/` และ `.env` ไว้แล้ว
- ไฟล์ใน `sample_data/` เป็นข้อมูลสมมติทั้งหมด สร้างจาก `tools/make_mock_data.py`

เทสต์ตรวจรับใช้ไฟล์ใน `sample_data/`:
- ผู้แจ้ง 50 ราย, ทะเบียน 40 คดีของ กก.1 (2568 = 15, 2569 = 25) + คดี กก.2 อีก 3 แถวที่ต้องไม่ถูกนำเข้า, จับคู่ได้ครบ
- ยังไม่สิ้นสุด 32 คดี: ไม่มีบ้านเลขที่ 5, ไม่มีจังหวัด 2, ขาดทั้งสองอย่าง 1 → ที่อยู่ไม่ครบ 6
- นำเข้าซ้ำแล้วไม่มีแถวเพิ่ม
- หมาย 1 ฉบับไม่มี `{` และใช้เลขไทย พ.ศ.
- หมาย 32 ฉบับรวมได้ PDF 1 ไฟล์ครบทุกคน

เทสต์ที่สร้าง PDF ต้องมี LibreOffice และ `pdftotext` (poppler-utils)

| งาน | คำสั่ง |
|---|---|
| สร้างไฟล์ตัวอย่างใหม่ | `python tools/make_mock_data.py` |
| สร้างแบบฟอร์มหมายเรียก v1/v2 ใหม่จากต้นฉบับ (ต้นฉบับไม่ถูกแก้ และไม่ต้อง commit) | `python tools/build_templates.py summons <ไฟล์ต้นฉบับ.docx>` |
| สร้างใบจ่าหน้าซองใหม่ | `python tools/build_templates.py envelope` |
| คอมไพล์ CSS ใหม่หลังแก้ template | ดูคำสั่งใน `tailwind.config.js` |
| ลบไฟล์เก่าใน media ทันที | `python manage.py cleanup_media` (worker รันให้ทุกวันอยู่แล้ว) |

โครงสร้างโปรเจกต์:
```
config/            settings, urls, celery
apps/core/         thai_format.py, สิทธิ์, AuditLog, หน้าตั้งค่า, คำสั่ง init_system / load_demo / cleanup_media
apps/accounts/     ผู้ใช้ + บทบาท
apps/registry/     Complainant, Case, Status, Unit, Investigator(+ชื่อในทะเบียน), AddressOverride, หน้าทะเบียน/คดี
apps/imports/      นำเข้า Excel, จับคู่คอลัมน์, รหัสไปรษณีย์, ประวัติ/ปัญหา
apps/documents/    แทนที่ตัวแทนใน Word, ออกหมาย, ตรวจ ม.53, PDF, รวมไฟล์/ZIP/ซอง, Celery
templates/         หน้าเว็บ (ภาษาไทย)
templates_docx/    แบบฟอร์ม Word ที่ระบบใช้
docker/            entrypoint, fontconfig สำรองสำหรับ TH Sarabun
```
