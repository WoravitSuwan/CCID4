# ระบบออกหมายเรียกผู้กล่าวหา (บก.สอท.4)

เว็บแอปภายในหน่วยงาน ทำหน้าที่ดังนี้
- นำเข้าข้อมูลผู้แจ้งและทะเบียนคดีจาก Excel แล้วรวมกันด้วยเลขรับแจ้ง
- คัดคดีที่ยังไม่สิ้นสุด
- ออกหมายเรียกผู้กล่าวหาจากแบบฟอร์ม Word ของหน่วย ได้ทีละคนหรือหลายร้อยคนพร้อมกัน
- ส่งออกเป็น Word / PDF พร้อมใบจ่าหน้าซอง

ข้อมูลทั้งหมดเก็บบนเครื่องภายในหน่วยงาน ระบบไม่เรียก API ภายนอกใดๆ

| ส่วนประกอบ | เทคโนโลยี |
|---|---|
| เว็บ | Python 3.12, Django 5.2, HTMX, Tailwind CSS (คอมไพล์ไว้แล้ว ไม่ต้องใช้อินเทอร์เน็ต) |
| ฐานข้อมูล | PostgreSQL 16 |
| งานเบื้องหลัง | Celery + Redis |
| เอกสาร | python-docx, docxcompose, LibreOffice (แปลง PDF) |

## เริ่มใช้งานด่วน (clone แล้วดับเบิลคลิก)

```bash
git clone https://github.com/WoravitSuwan/CCID4.git
```

### แบบที่ 1: รันบนเครื่องนี้ (ไม่ต้องมี Docker) — แนะนำสำหรับเริ่มต้น
ดับเบิลคลิก **`start-local.bat`** (macOS/Linux: `./start-local.sh`)

ครั้งแรกระบบจะ:
- หา Python 3.11 ขึ้นไป ถ้าไม่มีจะติดตั้ง Python 3.12 ให้ผ่าน winget (ติดตั้งเสร็จแล้วให้ดับเบิลคลิกอีกครั้ง)
- สร้าง `.venv` และติดตั้งแพ็กเกจ (ใช้เวลา 1–3 นาที ต้องต่ออินเทอร์เน็ตครั้งแรก)
- สร้างฐานข้อมูล SQLite ใน `data\` และบัญชีผู้ดูแลระบบ `admin` พร้อมรหัสผ่านสุ่ม
  - แสดงรหัสผ่านบนหน้าจอ และบันทึกไว้ใน `data\admin-password.txt`
- ถ้าไม่พบ LibreOffice จะถามว่าจะติดตั้งให้หรือไม่ (ไม่มี LibreOffice ก็ใช้งานได้และส่งออก Word ได้ แต่สร้าง PDF ไม่ได้)
- เปิดเบราว์เซอร์ที่ <http://localhost:8000>

ครั้งต่อไปดับเบิลคลิกไฟล์เดิม ระบบจะเปิดทันที ปิดระบบให้ปิดหน้าต่างสีดำ ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data\` และ `media\` (สำรองโดยคัดลอก 2 โฟลเดอร์นี้ขณะปิดระบบ)

| ต้องการ | ทำอย่างไร |
|---|---|
| ลองระบบด้วยข้อมูลสมมติ | เปิด Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วพิมพ์ `start-local.bat demo` (ใช้กับเครื่องทดลองเท่านั้น) |
| เปลี่ยนพอร์ต / ใช้ PostgreSQL แทน SQLite | สร้างไฟล์ `local.env` (บรรทัดละ `KEY=VALUE`) เช่น `PORT=8080` หรือ `POSTGRES_HOST=localhost` กับ `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` |
| ให้เครื่องอื่นในเครือข่ายเข้าใช้ | ใช้ที่อยู่ `http://<IP>:8000` ที่แสดงบนหน้าจอ และอนุญาต Python ใน Windows Firewall |

> **ฟอนต์:** ติดตั้ง TH SarabunIT๙ และ TH Sarabun New ใน Windows (คลิกขวาไฟล์ฟอนต์ → Install for all users) เพื่อให้ PDF ตรงกับแบบฟอร์ม

## 1. ติดตั้งบน Windows ด้วย Docker Desktop

### 1.1 เตรียมเครื่อง (ครั้งเดียว)
1. ติดตั้ง **Docker Desktop for Windows** (เปิดใช้ WSL 2 ตามที่ตัวติดตั้งแนะนำ) แล้วรีสตาร์ตเครื่อง
2. เปิด Docker Desktop ให้ขึ้นสถานะ *Engine running*
3. ใน Docker Desktop ไปที่ Settings → General แล้วติ๊ก *Start Docker Desktop when you sign in* เพื่อให้ระบบเปิดเองหลังรีสตาร์ต

### 1.2 นำโค้ดมาไว้ในเครื่อง
ดาวน์โหลดโค้ด (ZIP หรือ `git clone`) ไว้ที่ เช่น `C:\ccid4` แล้วเปิด **PowerShell** ในโฟลเดอร์นั้น

```powershell
cd C:\ccid4
```

### 1.3 ใส่ฟอนต์
คัดลอกไฟล์ฟอนต์ **TH SarabunIT๙** และ **TH Sarabun New** (.ttf ทั้งตัวปกติ ตัวหนา ตัวเอียง) ไปไว้ในโฟลเดอร์ `fonts\` ดูรายละเอียดใน [fonts/README.md](fonts/README.md)

> ถ้าไม่ใส่ฟอนต์ Docker image จะใช้ฟอนต์สำรอง "Sarabun Compat" (สร้างจาก Laksaman แล้วย่อให้ขนาดเท่า TH SarabunIT๙) PDF จะได้เลย์เอาต์ใกล้เคียงแบบฟอร์ม แต่รูปตัวอักษรต่างเล็กน้อย
> PDF จะใกล้เคียงแต่ตัวเลขไทยไม่ใช่แบบ IT๙ หลังใส่ฟอนต์ต้อง build ใหม่ (ข้อ 1.5)

### 1.4 ตั้งค่า
```powershell
Copy-Item .env.example .env
notepad .env
```
แก้อย่างน้อย `DJANGO_SECRET_KEY`, `POSTGRES_PASSWORD`, `DJANGO_SUPERUSER_PASSWORD`
ถ้าจะเปิดจากเครื่องอื่นผ่าน IP ให้ใส่ `DJANGO_CSRF_TRUSTED_ORIGINS=http://<IP เครื่องนี้>:8000`

สร้าง SECRET_KEY แบบสุ่มได้ด้วยคำสั่ง
```powershell
-join ((48..57)+(65..90)+(97..122) | Get-Random -Count 60 | % {[char]$_})
```

### 1.5 เปิดระบบ
```powershell
docker compose up -d --build
```
ครั้งแรกใช้เวลาหลายนาที (ดาวน์โหลด LibreOffice) จากนั้นเปิด <http://localhost:8000> แล้วล็อกอินด้วยผู้ดูแลระบบตามที่ตั้งไว้ใน `.env`

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `docker compose ps` | ดูสถานะ (ต้องมี web, worker, db, redis) |
| `docker compose logs -f web worker` | ดู log |
| `docker compose down` | ปิดระบบ (ข้อมูลยังอยู่) |
| `docker compose up -d --build` | เปิดใหม่ / อัปเดตหลังได้โค้ดใหม่ |

> ห้ามใช้ `docker compose down -v` เพราะ `-v` จะลบฐานข้อมูลทิ้ง

### 1.6 ตั้งค่าครั้งแรก (เมนู "ตั้งค่า" ด้วยบัญชีผู้ดูแลระบบ)
1. **หน่วย:** ตรวจ "สถานที่นัด" และ "ที่อยู่ผู้ส่ง" ของ กก.1
   - **กรอกของ กก.2** เพราะแบบฟอร์มที่ได้มามีเฉพาะที่อยู่ กก.1
   - คดีของ กก.2 ออกหมายไม่ได้จนกว่าจะกรอก
2. **นำเข้าข้อมูล:** นำเข้าทะเบียนคดีและไฟล์ผู้แจ้ง (ดูข้อ 2)
3. **พนักงานสอบสวน:** ผูก "ชื่อในทะเบียนที่ยังไม่ได้ผูก" กับพนักงานสอบสวน
   - กรอกยศเต็ม ชื่อที่ใช้ลงนาม ตำแหน่ง และโทรศัพท์ให้ครบ ข้อมูลนี้ใช้เป็นผู้ลงนามในหมาย
   - ระบบแนะนำชื่อใกล้เคียงให้ แต่ไม่ผูกเอง ชื่อเดียวกันที่เขียนต่างกัน (เช่น มี "หญิง" นำหน้า) ให้ผูกเข้าคนเดียวกัน
4. **สถานะคดี:** สถานะ "สิ้นสุด" เป็นสถานะสิ้นสุดเพียงตัวเดียวโดยค่าเริ่มต้น เปลี่ยนสถานะอื่นให้นับเป็นสิ้นสุดได้ (เช่น "ส่งสำนวนอัยการ")
5. **ผู้ใช้และสิทธิ์:** ระบบมีบทบาทผู้ใช้ 2 แบบเท่านั้น

| บทบาท | สิทธิ์ |
|---|---|
| ผู้ดูแลระบบ | ใช้งานได้ทุกส่วน: นำเข้า ทะเบียนคดี แก้สถานะ/ที่อยู่ ดูเลขบัตรเต็ม ออกหมาย ส่งออก มอบหมายงานโทร ตั้งค่า |
| เจ้าหน้าที่ติดต่อผู้เสียหาย (outsource) | เห็นเฉพาะคดีที่ได้รับมอบหมาย และเปิดได้แค่หน้ารายการโทรกับหน้าบันทึกผล ไม่เห็นเลขบัตร |

ผู้ดูแลระบบลดสิทธิ์หรือปิดบัญชีของตัวเองไม่ได้ และระบบต้องมีผู้ดูแลระบบที่ใช้งานอยู่อย่างน้อย 1 คนเสมอ บัญชีหัวหน้า ธุรการ และพนักงานสอบสวนที่มีอยู่เดิม จะถูกเปลี่ยนเป็นผู้ดูแลระบบอัตโนมัติเมื่ออัปเดตระบบ

ผู้ลงนามในหมายคือพนักงานสอบสวนเจ้าของคดีเสมอ (จากข้อ 3) ไม่ใช่ผู้ใช้ที่กดออก ระบบบันทึกชื่อผู้กดออกไว้ในบันทึกการใช้งาน

### 1.7 ลองระบบด้วยข้อมูลสมมติ (เครื่องทดสอบเท่านั้น)
```powershell
docker compose exec web python manage.py load_demo
```
คำสั่งนี้สร้างผู้ใช้ทดลอง 2 บัญชี: `admin` (ผู้ดูแลระบบ) และ `call1` (outsource) รหัสผ่าน `demo12345` **ห้ามรันบนเครื่องใช้งานจริง**

## 2. การใช้งาน

### นำเข้าข้อมูล
เมนู **นำเข้าข้อมูล** มี 5 ขั้นตอน: อัปโหลด → เลือกชีต → จับคู่คอลัมน์ → ตรวจสอบ → ยืนยัน
- **ข้อมูลผู้แจ้ง:** ไฟล์จากระบบรับแจ้งความออนไลน์ (ชีต `Grid`)
- **ทะเบียนคดี:** ไฟล์ทะเบียนของกอง เลือกชีตปีที่ต้องการได้
- **จับคู่คอลัมน์:** ระบบจับคู่จากชื่อหัวตารางอัตโนมัติ ถ้าหัวตารางเปลี่ยน ให้เลือกเอง ระบบจะจำไว้ใช้ครั้งหน้า
- **หน้าตรวจสอบ:** แสดง เพิ่มใหม่ / อัปเดต / มีปัญหา / จับคู่กับอีกไฟล์ไม่ได้ และสรุปสิ่งที่เปลี่ยน เช่น "สถานะเปลี่ยน 12 คดี"
  - ยังไม่มีอะไรถูกบันทึกจนกว่าจะกดยืนยัน
- **นำเข้าซ้ำ:** อัปเดตแถวเดิมตามเลขรับแจ้ง ไม่สร้างซ้ำ (ระบบตัดช่องว่างและแปลงเป็นตัวพิมพ์ใหญ่ก่อนเทียบ)
- **แถวที่มีปัญหา** (ไม่มีบ้านเลขที่, ไม่มีตำบล/อำเภอ/จังหวัด, เลขรับแจ้งซ้ำในไฟล์, เลขบัตรไม่ใช่ 13 หลัก) ยังนำเข้าได้แต่ติดธงไว้ ดาวน์โหลดรายการเป็น Excel ได้
- **รหัสไปรษณีย์:** ระบบเติมให้จาก ตำบล + อำเภอ + จังหวัด แยกเก็บจากค่าเดิม (ข้อมูลจาก [kongvut/thai-province-data](https://github.com/kongvut/thai-province-data) MIT License ฝังในระบบแล้ว)
  - ตอนกรอก/แก้ที่อยู่ในหน้าคดี ระบบเติมรหัสไปรษณีย์ให้ทันทีที่พิมพ์ตำบล/อำเภอ/จังหวัด ถ้าพื้นที่มีหลายรหัสจะให้เลือก ถ้าบันทึกโดยเว้นช่องว่าง ระบบเติมให้ตอนบันทึก
  - ข้อมูลที่นำเข้าไว้แล้วเติมย้อนหลังด้วย `python manage.py fill_postcodes` (ระบบรันให้เองทุกครั้งที่เริ่ม)
  - ใช้ตารางรหัสไปรษณีย์ที่ฝังในระบบ ไม่ส่งข้อมูลไปที่บริการภายนอก
- **คดีที่จับคู่ไม่ได้:** นำเข้าได้ แต่ออกหมายไม่ได้จนกว่าจะจับคู่ได้หรือกรอกที่อยู่เอง เมื่อนำเข้าไฟล์ผู้แจ้งรอบใหม่ ระบบจับคู่ให้อัตโนมัติ
- **ผู้แจ้งที่ไม่อยู่ในทะเบียน:** เก็บไว้ แต่ไม่แสดงในทะเบียนคดี

### ทะเบียนคดีและรายละเอียดคดี
- ค้นหาและกรองได้ตามสถานะ ปี หน่วย พนักงานสอบสวน ประเภทคดี
- แท็บ **ยังไม่สิ้นสุด / สิ้นสุดแล้ว / ทั้งหมด** พร้อมจำนวนคดี และเรียงตามวันที่รับแจ้ง (ใหม่→เก่า หรือ เก่า→ใหม่) หรือตามเวลาแก้ไขล่าสุด
- แก้สถานะได้จากช่องสถานะในแต่ละแถวโดยตรง ระบบบันทึกเวลาและผู้แก้ไว้
- ปุ่มลัด: ยังไม่สิ้นสุด / ที่อยู่ไม่ครบ / จับคู่ไม่ได้ / ยังไม่เคยออกหมาย
- **ส่งออก Excel** ได้คอลัมน์เดิม แยกชีตตามชีตต้นทาง
- **แก้ที่อยู่ในหน้าคดี:** ระบบเก็บที่อยู่ที่แก้แยกไว้และใช้ที่อยู่นี้ก่อนเสมอ ไฟล์ผู้แจ้งรอบใหม่จะไม่ทับ
  - ถ้าที่อยู่ในไฟล์ใหม่เปลี่ยนไป ระบบจะเตือนให้เลือกว่าจะใช้อันไหน
- **เลขบัตรประชาชน:** แสดงแบบ `x-xxxx-xxxxx-12-3` ผู้มีสิทธิ์กด "แสดง" ได้ และระบบบันทึกทุกครั้งที่กดดู

### ออกหมายเรียก
1. ในทะเบียนคดี ติ๊กเลือกคดี แล้วกด **ออกหมายเรียก (n รายการ)** หรือ "ออกหมายทุกคดีที่ตรงตัวกรอง"
2. ตั้งค่าหมาย:
   - วันนัดเริ่มต้น = วันออกหมาย + 14 วัน (ตรงเสาร์/อาทิตย์เลื่อนเป็นวันจันทร์) เวลา 09.00 น.
   - เลือก "ไล่เวลาทีละ 30 นาที" ได้ (ไล่แยกตามพนักงานสอบสวน)
3. ระบบจัดกลุ่มตามผู้ลงนาม และตรวจข้อความที่ ป.วิ.อ. มาตรา 53 กำหนด รายการที่ไม่ครบจะแสดงเหตุผลและไม่ถูกออกหมาย
4. กด **ดูตัวอย่าง PDF** เพื่อตรวจ แล้วกด **ยืนยันออกหมาย**
   - ตัวเลือก "เปลี่ยนสถานะคดีเป็น 'ออกหมายเรียก'" ค่าเริ่มต้นไม่ติ๊ก
5. ระบบพาไปหน้า **ส่งออก**:
   - เลือก PDF / Word / ทั้งสองแบบ
   - เลือกรวมเป็นไฟล์เดียว (ขึ้นหน้าใหม่ทุกคน) หรือแยกรายคนใส่ ZIP
   - เลือกพิมพ์ใบจ่าหน้าซองพร้อมกันได้
   - เกิน 20 ฉบับจะทำงานเบื้องหลังและแสดงความคืบหน้า
6. บันทึกผลหมาย (มาตามนัด / ไม่มา / ยกเลิก) ได้ในหน้ารายละเอียดคดี

ไฟล์ที่ส่งออกถูกลบอัตโนมัติหลัง N วัน (ตั้งในเมนู ตั้งค่า → ระบบ) หมายเรียกที่ไฟล์ถูกลบแล้วสร้างใหม่ได้เหมือนเดิมทุกตัวอักษร เพราะระบบเก็บค่าที่ใช้ไว้

### ติดต่อผู้เสียหายทางโทรศัพท์ (เจ้าหน้าที่ outsource)

**1. สร้างบัญชีผู้โทร:** ไปที่ ตั้งค่า → ผู้ใช้และสิทธิ์ แล้วเลือกบทบาท **"เจ้าหน้าที่ติดต่อผู้เสียหาย (outsource)"**
- บัญชีนี้เห็นเฉพาะคดีที่ได้รับมอบหมาย และเปิดได้แค่หน้ารายการโทรกับหน้าบันทึกผล
- ไม่เห็นเลขบัตรประชาชน ออกหมายไม่ได้ ส่งออกไม่ได้

**2. มอบหมาย case id:** ทำได้ 2 วิธี (ผู้ดูแลระบบ)
- เมนู **ติดต่อผู้เสียหาย → มอบหมายเลขรับแจ้ง** วางเลขรับแจ้งที่คัดลอกจาก Excel แล้วเลือกผู้โทร
- ในทะเบียนคดี ติ๊กเลือกคดี แล้วกด **มอบหมายให้โทร** ที่แถบด้านล่าง

**3. ผู้โทรบันทึกผล:** เปิดรายการที่ต้องโทร → กดเบอร์เพื่อโทร → เลือกผล → กด **"บันทึก แล้วไปคดีถัดไป"**

| ผลที่เลือกได้ | ผลต่องานโทร |
|---|---|
| ติดต่อได้ – นัดเข้าพบพนักงานสอบสวน (ต้องระบุวันเวลานัด) / ให้ข้อมูลเพิ่มเติมแล้ว / ไม่ประสงค์ดำเนินคดีต่อ / อื่นๆ | งานโทรคดีนั้นเสร็จ |
| ติดต่อได้ – ขอให้โทรกลับภายหลัง (ต้องระบุเวลา) | ซ่อนจากแท็บ "ต้องโทร" จนถึงเวลานัด |
| ติดต่อไม่ได้ – ปิดเครื่อง / ไม่รับสาย / สายไม่ว่าง / ฝากข้อความไว้ | ยังอยู่ในรายการต้องโทร (ระบุเวลาโทรกลับได้) |
| ปลายทางแจ้งว่าไม่รู้จักผู้เสียหาย / เบอร์ไม่ถูกต้อง | งานโทรเสร็จ (เปิดใหม่ได้ในหน้าบันทึกผล) |

**4. ติดตามผล:**
- หน้า "ติดต่อผู้เสียหาย" แสดงความคืบหน้าแยกตามผู้โทร
- **ส่งออกผลการโทร (Excel)** ได้ทุกครั้งที่โทร
- ในทะเบียนที่ส่งออก คอลัมน์ "บันทึกการติดต่อ" จะต่อท้ายผลจากระบบในรูปแบบเดิม เช่น `ครั้งที่ 1 ไม่สามารถติดต่อได้ (ปิดเครื่อง) 9 ตค 69 เวลา 10.30 น.`
- การบันทึกผลทุกครั้งเก็บใน AuditLog และแสดงในหน้ารายละเอียดคดี

### แก้ไขสถานะคดี
- แก้ได้ในหน้ารายละเอียดคดี หรือเลือกหลายคดีในทะเบียนแล้วเลือก "เปลี่ยนสถานะเป็น…"
- ถ้านำเข้าไฟล์ทะเบียนที่ยังระบุสถานะเดิม ระบบจะคงสถานะที่แก้ไว้ ถ้าไฟล์ระบุสถานะใหม่ ระบบจะใช้ค่าจากไฟล์

## 4. สำรองและกู้คืนข้อมูล

ข้อมูลอยู่ใน Docker volume 2 ส่วน:
- `pgdata`: ฐานข้อมูล
- `media`: ไฟล์ที่อัปโหลดและไฟล์ที่ส่งออก

**สิ่งที่ต้องสำรองทุกวันคือฐานข้อมูล** ส่วน media สร้างใหม่ได้

### สำรอง
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\backup.ps1
```
สคริปต์จะ dump ฐานข้อมูลภายใน container แล้วคัดลอกออกมาเป็น `C:\ccid4-backup\summons_ปีเดือนวัน_เวลา.dump` และลบไฟล์สำรองที่เก่ากว่า 30 วัน
(ไม่ใช้ `pg_dump > ไฟล์` ใน PowerShell เพราะ PowerShell จะแปลงข้อมูลจนไฟล์เสีย)

**สำรองอัตโนมัติทุกวัน:** เปิด Task Scheduler → Create Basic Task → Daily แล้วตั้งค่าดังนี้
- Action: Start a program
- Program: `powershell.exe`
- Arguments: `-NoProfile -ExecutionPolicy Bypass -File C:\ccid4\tools\backup.ps1`

ควรคัดลอกไฟล์ `.dump` ไปเก็บอีกที่หนึ่งด้วย (เช่น ฮาร์ดดิสก์ภายนอกที่เข้ารหัส) เพราะเป็นข้อมูลส่วนบุคคล

### กู้คืน
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\restore.ps1 -File C:\ccid4-backup\summons_20260209_0200.dump
```
สคริปต์จะถามยืนยัน แล้วหยุด web/worker กู้คืน และเปิดกลับให้เอง
